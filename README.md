# DELL_LATITUDE_6430U_EFI_HACKINTOSH
OpenCore EFI for DELL LATITUDE 6430U running macOS Big Sur

bootloader: OpenCore
SMBIOS: MacBookPro11,1
CPU: Intel Core i7-3667U (Ivy Bridge)
GPU: Intel HD 4000
RAM: 8GB DDR3

fully working (Recommended):
- Big Sur
- Catalina
- Mojave
- High Sierra
- Sierra

Older versions (install & boot, limited support):
- El Capitan - works, but no Wi-Fi
- Yosemite - works, but no Wi-Fi
- Mavericks - works, but no Wi-Fi

Partially Working
- Monterey - system installs and runs, but graphics acceleration does not work

Not Working
- Ventura and later - does not install or boot
